# Purpose

This document defines the first internal draft of the Wellbine Privacy Policy.

This is not the final legal document.

This draft exists to align product, data, app release, user trust and legal review before publication.

The final Privacy Policy should be reviewed by qualified legal counsel before being published.

---

# Official Definition

**The Wellbine Privacy Policy explains how Wellbine collects, uses, stores, protects and manages user data, including account data, profile data, wellness context, wearable data, uploads, AI-assisted guidance, Push interactions, Daily activity, Daily Stack data, Commerce Bridge activity and app usage information.**

---

# Core Principle

The core privacy rule is:

```text
Collect only what is useful, explain it clearly and give the user control.
```

Wellbine should avoid collecting unnecessary data.

Wellbine should avoid storing excessive raw health data.

Wellbine should avoid unclear privacy language.

Wellbine should make privacy part of the product experience, not only a legal page.

---

# Product Boundary

Wellbine is an adaptive wellness guidance system.

Wellbine is not:

- A medical diagnosis service
- A medical treatment service
- An emergency service
- A clinical monitoring device
- A replacement for a doctor
- A replacement for licensed medical advice

Privacy language should match this product boundary.

# Privacy Policy

**Effective Date:** [Insert Date]

Wellbine respects your privacy.

This Privacy Policy explains how Wellbine collects, uses, stores and protects information when you use the Wellbine app, website, services or related features.

By using Wellbine, you agree to the practices described in this Privacy Policy.

If you do not agree with this Privacy Policy, you should not use Wellbine.

# What Wellbine Is

Wellbine is an adaptive wellness guidance system designed to help users organize daily routines across areas such as sleep, movement, hydration, nutrition, mind, sunlight, Daily Stack, recovery and daily wellness behaviors.

Wellbine may use user-provided information, app activity, optional wearable data and AI-assisted guidance to personalize the user experience.

Wellbine does not provide medical diagnosis, medical treatment or emergency care.

---

# Information We Collect

Wellbine may collect different types of information depending on how the user interacts with the product.

The information may include:

- Account information
- Profile information
- Wellness preferences
- Onboarding answers
- Daily activity
- Pillar activity
- Push notification responses
- Daily Stack information
- Optional wearable data
- Optional uploaded files
- AI interaction context
- App usage information
- Subscription status
- Commerce Bridge activity
- Device and technical information

Wellbine should collect only the information needed to provide and improve the service.

---

# Account Information

We may collect account information such as:

- Name
- Email address
- Authentication identifier
- Account status
- Subscription status
- Language preference
- Timezone
- App settings

This information is used to create and manage the user account.

---

# Profile Information

During onboarding or later use, Wellbine may collect profile information such as:

- Name
- Age
- Biological sex
- Height
- Weight
- Country or region
- Language
- Timezone
- General wellness goals
- Relevant health-related context provided by the user

This information helps Wellbine personalize daily guidance.

The user may choose not to provide optional information.

# Biological Sex

Wellbine may ask for biological sex for physiological personalization.

This field is used for wellness context and product personalization.

It is not intended to define gender identity.

The user may be offered an option such as:

```text

```

# Health And Wellness Context

Wellbine may collect health-related or wellness-related context provided by the user.

This may include:

- Sleep habits
- Movement habits
- Hydration habits
- Nutrition preferences
- Stress or mood check-ins
- Recovery signals
- Wellness goals
- Daily routine preferences
- Relevant comorbidities voluntarily provided by the user
- Daily Stack items
- User feedback on guidance

Wellbine uses this information to personalize daily wellness guidance.

Wellbine does not use this information to diagnose, treat or cure medical conditions.

---

# Wearable And Health Platform Data

Wearable connection is optional.

If the user chooses to connect a wearable device or health platform, Wellbine may process data such as:

- Sleep duration
- Sleep regularity
- Resting heart rate
- Heart rate variability
- Steps
- Active minutes
- Movement trends
- Respiratory rate
- Oxygen saturation
- Temperature trends
- Recovery or readiness indicators
- Stress-related indicators when available

The exact data depends on the connected provider and user permissions.

Possible sources may include:

- Apple Health
- Google Health Connect
- Garmin
- Oura
- WHOOP
- Fitbit
- Other supported providers

Wellbine should not claim integration with providers that are not actually implemented.

---

# Wearable Data Usage

Wearable data may be used to:

- Personalize Daily guidance
- Improve Home insights
- Adjust recovery-aware suggestions
- Improve Pillar states
- Support AAI context
- Reduce the need for manual check-ins
- Improve timing of recommendations

Wearable data is optional.

Wellbine must continue working even if no wearable is connected.

Uploaded files may be used to:

- Summarize relevant information
- Improve Daily guidance
- Improve Plan adaptation
- Support AAI context
- Help the user organize health-related information

Uploaded files should not be used to provide medical diagnosis.

The user should be able to delete uploaded files where technically and legally possible.

Wellbine may use AI-assisted systems to help organize user context and suggest practical wellness actions.

AI may help with:

- Daily guidance
- Plan adaptation
- Pillar interpretation
- Contextual recommendations
- Upload summaries
- Daily Stack organization
- User questions
- Adaptive next actions

# AAI Context

Wellbine may use Adaptive Alignment Intelligence, or AAI, to understand context, continuously learn, anticipate needs, align systems and optimize outcomes.

AAI may process:

- User profile
- Active plan
- Daily behavior
- Pillar state
- Wearable summaries
- User settings
- Push responses
- Upload summaries
- Recommendation history
- Commerce Bridge context when relevant

AAI should use data to improve the user experience, not to create unnecessary surveillance.

# Push Notifications

Wellbine may use Push notifications to guide the user's day.

Push may be used for:

- Daily check-ins
- Confirm / Adjust / Later actions
- Recovery-aware prompts
- Plan reminders
- Daily Stack reminders
- Sleep preparation
- Hydration reminders
- Movement reminders
- Subscriber benefit notifications when relevant and allowed

Push is optional.

The user can disable Push notifications through device settings and may also control notification preferences inside Wellbine where available.

Mental Detox may help users manage:

- Notification frequency
- App interruptions
- Push preferences
- Focus periods
- Daily guidance rhythm

Mental Detox settings may be stored to personalize notification behavior.

# Daily Stack

Wellbine may allow users to organize supplements, vitamins, nutraceuticals, medications or routine items through Daily Stack.

Daily Stack information may include:

- Item name

- Timing
- Frequency
- Dosage text
- User confirmation
- Refill context
- User notes

Daily Stack helps organize routines.

It does not replace professional medical advice.

Users should consult qualified professionals before changing medications or medical treatments.

# Commerce Bridge

Wellbine may include Commerce Bridge features.

Commerce Bridge may process:

- Benefit eligibility

- Benefit usage
- Button click events
- Coupon copy events
- External store opening events
- Campaign-related metadata
- Subscription status when relevant

Purchases may occur outside Wellbine through external e-commerce platforms.

External stores may have their own privacy policies and terms.

Wellbine is not responsible for the privacy practices of third-party external stores.

# Data Security

Wellbine should use reasonable technical and organizational measures to protect user data.

Security measures may include:

- Authentication
- Access controls
- Row Level Security
- Private storage buckets
- Encryption in transit
- Restricted admin access
- Audit logs
- Secure backend functions
- Separation of user-owned data
- Monitoring and error reporting

No system can guarantee absolute security.

Users should keep their login credentials secure.

---

# Row Level Security

Wellbine uses Supabase as a source of truth.

User-owned data should be protected so that users can access only their own private data.

Admin-managed data should be restricted to authorized personnel.

Service role keys should never be exposed to the frontend.

# What Privacy Policy Should Not Do

The Privacy Policy should not:

- Claim data is not collected if it is collected
- List providers that are not actually used
- Hide health data usage
- Hide AI usage
- Hide wearable usage
- Hide upload processing
- Hide commerce tracking
- Promise absolute security
- Promise deletion behavior that is not implemented
- Use vague language around sensitive data
- Contradict the app experience
- Contradict App Store or Google Play disclosures

- Users can understand what data Wellbine collects
- Users can understand why data is used
- Users can understand optional features
