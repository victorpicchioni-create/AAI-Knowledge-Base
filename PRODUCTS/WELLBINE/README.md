# Purpose

This document introduces Wellbine, the first product built using the Adaptive Alignment Intelligence (AAI) framework.

Wellbine applies AAI to health, performance and longevity through context-aware guidance, intelligent routines and adaptive intervention.

---

# Product Definition

Wellbine is not just a habit tracker.

Wellbine is not just a health app.

Wellbine is not just an AI assistant.

Wellbine is an Adaptive Human Operating System designed to help users improve health, performance and longevity with minimal cognitive effort.

---

# Relationship With AAI

AAI is the intelligence architecture.

Wellbine is the first product implementation of AAI.

In Wellbine, AAI is responsible for:

- Understanding user context
- Learning from behavior
- Anticipating needs
- Guiding the next best action
- Improving outcomes over time

---

# Core Methodology

Wellbine uses a product-specific methodology called BCAS.

BCAS means:

**Biological Context Alignment System**

BCAS organizes user guidance based on biological context instead of rigid clock-based routines.

---

# Current Stack

Wellbine is currently designed to be developed using:

- FlutterFlow
- Supabase
- Firebase Cloud Messaging for Push Notifications

The current product direction prioritizes speed, simplicity and practical execution.
